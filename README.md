# Portfolio Website

## Deskripsi

Website portfolio pribadi yang dibuat untuk memenuhi tugas Slicing Website pada mata kuliah Pemrograman Berbasis Web.

Website ini dibuat menggunakan HTML, CSS, dan JavaScript tanpa menggunakan framework seperti Bootstrap atau Tailwind CSS.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- DOM

## Fitur Website

- Responsive design untuk desktop, tablet, dan mobile
- Responsive navbar
- Hamburger menu pada tampilan mobile
- Dark mode
- Contact form
- Navigasi antar section
- Tampilan portfolio dan project

## Section Website

Website terdiri dari beberapa bagian:

1. Home
2. About
3. Skills
4. Projects
5. Contact

## Responsive Design

Website dibuat agar dapat menyesuaikan ukuran layar:

- Desktop
- Tablet
- Mobile
